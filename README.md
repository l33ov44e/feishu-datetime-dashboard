# 飞书仪表盘 - 日期时间插件

这是一个飞书仪表盘插件，用于显示当前日期和时间。支持多种自定义选项，包括时区选择、日期/时间格式设置、字体大小和颜色调整以及时区显示控制。

![插件预览](preview.png)

## 功能特性

- 实时显示当前日期和时间
- 支持多种时区选择
- 可自定义日期和时间的显示格式
- 可调节显示字体大小和颜色
- 支持单独显示日期或时间
- 可控制时区信息的显示/隐藏
- 响应式设计，适配不同屏幕尺寸
- 中文界面，符合国内用户使用习惯

## 安装和部署

### 方法一：使用已构建版本

1. 下载 `dist` 目录中的所有文件
2. 将这些文件部署到您的 Web 服务器上
3. 在飞书仪表盘中添加自定义页面，并指向您的部署地址

### 方法二：本地构建

```bash
# 克隆或下载项目
git clone <项目地址>

# 进入项目目录
cd feishu-datetime-dashboard

# 安装依赖
npm install

# 构建项目
npm run build
```

构建完成后，所有文件将位于 `dist` 目录中，您可以将其部署到任何 Web 服务器。

## 使用说明

1. 在飞书仪表盘中添加新的自定义页面组件
2. 插件加载后，会自动进入配置模式
3. 您可以在配置面板中：
   - 选择时区
   - 设置是否显示日期和时间
   - 控制时区信息的显示/隐藏
   - 自定义日期和时间格式
   - 调整字体大小和颜色
4. 配置完成后点击"保存配置"
5. 插件将以设定的格式显示当前日期和时间

## 自定义选项

### 时区选择
支持全球多个常用时区，包括：
- 协调世界时 (UTC)
- 中国标准时间 (GMT+8)
- 日本时间 (GMT+9)
- 韩国标准时间 (GMT+9)
- 纽约时间 (GMT-5/-4)
- 洛杉矶时间 (GMT-8/-7)
- 伦敦时间 (GMT+0/+1)
- 巴黎时间 (GMT+1/+2)

### 日期格式
- 年-月-日 (YYYY-MM-DD)
- 月/日/年 (MM/DD/YYYY)
- 日/月/年 (DD/MM/YYYY)
- 月份 日, 年 (MMM DD, YYYY)

### 时间格式
- 24小时制 (HH:mm:ss)
- 12小时制 (hh:mm:ss A)
- 无秒显示 (HH:mm)

### 显示控制
- 日期显示开关
- 时间显示开关
- 时区显示开关
- 字体大小调节 (12px-72px)
- 字体颜色选择
