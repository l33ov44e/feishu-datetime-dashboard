# 飞书仪表盘 - 日期时间插件

这是一个飞书仪表盘插件，用于显示当前日期和时间。支持多种自定义选项，包括时区选择、日期/时间格式设置以及字体大小调整。

## 功能特性

- 实时显示当前日期和时间
- 支持多种时区选择
- 可自定义日期和时间的显示格式
- 可调节显示字体大小
- 支持单独显示日期或时间
- 响应式设计，适配不同屏幕尺寸

## 安装和部署

### 方法一：使用已构建版本

1. 下载 `dist` 目录中的所有文件
2. 将这些文件部署到您的 Web 服务器上
3. 在飞书仪表盘中添加自定义页面，并指向您的部署地址

### 方法二：本地构建

```bash
# 克隆或下载项目
git clone <项目地址>

# 进入项目目录
cd feishu-datetime-dashboard

# 安装依赖
npm install

# 构建项目
npm run build
```

构建完成后，所有文件将位于 `dist` 目录中，您可以将其部署到任何 Web 服务器。

## 使用说明

1. 在飞书仪表盘中添加新的自定义页面组件
2. 插件加载后，会自动进入配置模式
3. 您可以在配置面板中：
   - 选择时区
   - 设置是否显示日期和时间
   - 自定义日期和时间格式
   - 调整字体大小
4. 配置完成后点击"保存配置"
5. 插件将以设定的格式显示当前日期和时间

## 自定义选项

### 时区选择
支持全球多个常用时区，包括：
- UTC
- Asia/Shanghai (GMT+8)
- Asia/Tokyo (GMT+9)
- Asia/Seoul (GMT+9)
- America/New_York (GMT-5/-4)
- America/Los_Angeles (GMT-8/-7)
- Europe/London (GMT+0/+1)
- Europe/Paris (GMT+1/+2)

### 日期格式
- YYYY-MM-DD (例如: 2025-12-16)
- MM/DD/YYYY (例如: 12/16/2025)
- DD/MM/YYYY (例如: 16/12/2025)
- MMM DD, YYYY (例如: Dec 16, 2025)

### 时间格式
- 24小时制 (HH:mm:ss)
- 12小时制 (hh:mm:ss A)
- 无秒显示 (HH:mm)
